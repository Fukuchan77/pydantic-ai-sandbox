Generated by `/sdd-tasks`. TDD（赤 → 緑）を各実行可能契約で行い、検証結果は evidence として残す。

Conventions:
- `- [ ]` pending, `- [x]` done, `- [ ]*` optional/deferrable test.
- `(P)` = safe to run in parallel (no dependency, disjoint boundary).
- Every task (major and sub) declares `_Boundary:_`, `_Depends:_`, `_Requirements:_`, and `_Traces:_`.
- Requirement coverage lists numeric IDs only, comma-separated.
- option (c) の OpenAI compatibility contract が失敗した場合は実装を止め、option (a) を含む plan amendment 後にタスクを再生成する。
- root `tests/unit/` に赤のテストを置くタスクグループ（1・2・3）は 1 → 2 → 3 の順に直列で実行する。赤のテストは単独でコミットせず、赤の観測（コマンドと失敗 assert）は PDCA ログに残し、同じグループの緑化までを一続きのコミット列にする。別タスクの完了 gate（`mise run check`・`mise run cov`）を測る時点で、作業ツリーに赤のテストを残さない。
- 赤のテストが成立しない文書・構造タスク（1.2 の統治文書同期、4、5.1、5.2）は、変更前の該当箇所（ledger の行・README の検証記録・憲法の版行）を `git show HEAD:<path>` で引用したものを代替の失敗証拠として PDCA ログに残す（憲法 Principle 5）。
